 🌾 KrishiMitra AI

> **Your AI-Powered Smart Farming Companion**

KrishiMitra AI is an **offline-first, AI-powered smart farming platform** designed to help farmers make informed decisions throughout the farming lifecycle. It combines financial management, crop disease detection, soil health tracking, marketplace access, and AI assistance into one easy-to-use application.

## 🎯 Mission

Empower farmers with accessible AI technology to improve productivity, profitability, and sustainability while keeping the app simple enough for everyday use.



## 🌟 Key Features

* 👤 Phone OTP Authentication
* 🌱 Farm & Crop Management
* 💰 Expense & Income Tracking
* 📊 Profit & Loss Analytics
* 🦠 AI Crop Disease Detection from Photos
* 🌾 Soil Health Record Keeper
* 🔔 Smart Farming Reminders
* 🎤 Voice-Based Data Entry
* 🛒 Farmer-to-Buyer Marketplace
* 📡 Offline-First Support
* 🤖 AI Farming Assistant
* 🌐 Multi-language Support (Planned)


## 🛠️ Tech Stack

* **Frontend:** React.js + Tailwind CSS
* **Backend:** Supabase
* **Database:** PostgreSQL
* **AI:** Google Gemini API + Genkit
* **Voice:** Web Speech API
* **Offline:** PWA + Dexie.js (IndexedDB)
* **Deployment:** Vercel krishi-mitr-ai-xi.vercel.app


## 📖 Why "KrishiMitra AI"?

* **Krishi** = Agriculture/Farming
* **Mitra** = Friend/Companion

Together, **KrishiMitra AI** means **"An AI Friend for Farmers"**—a trusted assistant that helps farmers manage finances, protect crops, maintain soil health, and access markets more effectively.
